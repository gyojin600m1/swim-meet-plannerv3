# Swim Meet Day Planner

水泳大会当日の流れを、レース時刻から逆算して時系列で整理する単一HTMLアプリです。
朝食・補食・陸アップ・水中アップ・直前準備・レース後の回復までを1日のタイムラインで表示します。

依存ライブラリなし。`index.html` をブラウザで開くだけで動きます。

## 特長

- **レース時刻からの逆算タイムライン** — 種目の負荷（短/中/長距離）に応じて補食・アップ・直前準備の時刻を自動算出
- **入力の自動保存** — `localStorage` に保存。リロードや次の大会でも前回の入力を復元
- **チェック（警告）パネル** — W-UP終了が1本目より後／到着がW-UP開始より後／補食が到着前／レース間隔が短すぎ など当日の時間衝突を検知
- **相対ラベル** — 各イベントが「レースの何分前か」を表示
- **テキストでコピー** — 当日の流れをLINE・メモに貼れる整形テキストで出力
- **印刷 / PDF** — タイムラインだけを紙やPDFに出力（会場持ち込み用）
- **スマホ対応** — レスポンシブ。レース入力欄にもモバイル用ラベル表示

## 使い方

1. `index.html` をブラウザで開く
2. 大会要項の朝スケジュール（開門・W-UP・公式スタート練習など）を入力
3. レース時刻と負荷感を入力して「プラン生成」
4. 「テキストでコピー」または「印刷 / PDF」で持ち出し

## GitHub Pages で公開する

1. このリポジトリを GitHub に push
2. Settings → Pages → Branch を `main` / `(root)` に設定
3. 発行された URL で `index.html` が公開されます
