# 大会当日プラン

競泳大会当日の過ごし方を、レース時刻から逆算して時系列で整理するスマホ対応アプリです。
朝食・補食・陸アップ/チューブ・水中アップ・招集前の直前準備・レース後の回復・次のレースまでの過ごし方を、
1日〜複数日（予選/決勝が別日の大会など）の流れで表示します。

依存ライブラリなし。`index.html` をブラウザで開くだけで動きます。

## 特長

- **1日〜複数日対応** — 「日を追加」で大会の日数分だけセクションを増やせる。各日ごとに要項（起床・会場到着・開門・W-UP・公式スタート練習など）とレースを個別に入力
- **レース時刻からの逆算タイムライン** — 種目の負荷（短/中/長距離）に応じて補食・陸アップ/チューブ・水中アップ・直前準備の時刻を自動算出
- **段階的な補食タイミング** — レース前に2時間前/1時間前/30分前の3段階で補食を提案（鹿児島県水泳連盟 栄養士コラムを参考）。レース間隔が短い時は自動的に段階を間引いて1回の軽い補食にまとめる
- **入力の自動保存** — `localStorage` に保存。リロードや次の大会でも前回の入力（日数・各日の内容）を復元
- **チェック（警告）パネル** — W-UP終了が1本目より後／到着がW-UP開始より後／補食が到着前／レース間隔が短すぎ など当日の時間衝突を日ごとに検知
- **相対ラベル** — 各イベントが「レースの何分前か」を表示
- **テキストでコピー** — 日ごとに区切った当日の流れをLINE・メモに貼れる整形テキストで出力
- **印刷 / PDF** — タイムラインだけを紙やPDFに出力（会場持ち込み用）
- **スマホ対応** — レスポンシブ。レース入力欄・日程入力欄にもモバイル用ラベル表示

## 使い方

1. `index.html` をブラウザで開く
2. 選手名を入れ、大会が1日なら1日分のまま、複数日大会は「＋ 日を追加」で日数分増やす
3. 各日の朝スケジュール（開門・W-UP・公式スタート練習など）とレース時刻・負荷感を入力して「プラン生成」
4. 「テキストでコピー」または「印刷 / PDF」で持ち出し

## 入力の考え方

- 選手本人がその日に出場する種目・時刻を入力する方式です。大会プログラム全体（他の選手を含む出場者一覧）は取り込みません。
- 各大会の要項・プログラムに二次利用や転載を禁じる記載がないか、入力前に必ず確認してください。

## GitHub Pages で公開する

1. このリポジトリを GitHub に push
2. Settings → Pages → Branch を `main` / `(root)` に設定
3. 発行された URL で `index.html` が公開されます

## 補食タイミングの出典

レース前の2時間前/1時間前/30分前の段階的な補食タイミングは、鹿児島県水泳連盟 栄養士 西山七海氏によるコラム
「大会の時の補食って何を食べたらいいの？？」（[2026年7月号PDF](https://www.kagoshima-swim.com/new/wp-content/uploads/2026/06/202607_Column.pdf)）
を参考に要約したものです。原文・イラストの転載ではなく、当アプリの表現・タイムライン形式に書き直しています。
